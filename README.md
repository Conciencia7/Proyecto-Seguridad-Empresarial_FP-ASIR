# Proyecto de Seguridad Empresarial

## Descripción

Proyecto de implantación y mejora de medidas de seguridad en una infraestructura empresarial para proteger, controlar y monitorizar los sistemas y datos corporativos.

## Objetivo
Implantar un sistema de seguridad que permita proteger, controlar y monitorizar los datos y sistemas corporativos, reduciendo los riesgos de seguridad y mejorando la gestión de la información.

## Funcionalidades principales

- [ ] Configuración y actualización del firewall.
- [ ] Gestión de usuarios y permisos por roles.
- [ ] Implementación de acceso seguro mediante SSH.
- [ ] Aplicación de políticas de contraseñas.
- [ ] Configuración de copias de seguridad automáticas.
- [ ] Monitorización de servidores y servicios.

##Funcionalidades secundarias
- [ ] Implementación de VPN corporativa.
- [ ] Segmentación de red mediante VLAN.
## Tecnologías

```
Windows Server
Active Directory
SSH
Firewall (UFW o pfSense)
Git y GitHub
VirtualBox
Zabbix o Nagios
```
